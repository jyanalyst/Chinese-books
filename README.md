# 红车比赛 (The red car race)

A small Mandarin interactive picture book for a young child, for iPad Safari in landscape.
Plain HTML/CSS/JS, no build step, works offline. Voice: generated TTS clips (no personal recordings).

Unlisted on purpose: `noindex, nofollow` meta tag and `robots.txt` (`Disallow: /`). No analytics, no network calls
beyond this site, no personal data (the hero name is a placeholder; a parent can change it on the device only).
